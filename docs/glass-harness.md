# Glass rendering harness

`/glass-harness` は、トップページと同じ WebGL 描画を工程別に確認するための検証画面です。

## 確認順序

1. **Source alignment** — ガラス内外で背景の位置と色が一致すること。
2. **Frost blur** — 背景の輪郭が滑らかにぼけ、四角いピクセルや多重像が出ないこと。
3. **Rim mask** — 白い帯が四辺と角丸に連続し、途中で途切れないこと。
4. **Surface scatter** — 差分が微細かつ滑らかで、格子状にならないこと。
5. **Final composite** — 背景が透けたまま、リムだけで位置が湾曲して見えること。

リムは、シャープな背景を法線方向へずらして高いアルファで置き換えます。中央面の透明度とは独立しているため、中央を透明にしても屈折が消えない構成です。

リムの白い反射は全周一律ではなく、`Light X / Y` とエッジ法線の内積で決まります。標準値は左上光源です。右辺と下辺には白を足さず、屈折色と陰影を残します。

中間ターゲットは線形RGBで処理し、最終合成時だけ画面用sRGBへ変換します。この変換が抜けると、暗色は黒い縁、明色は白い縁として潰れて見えます。

`Background coverage` は常に `100.0%` にします。100% 未満では、Canvas が背景画像外の代替色を読むため、不透明化・白飛び・色抜けに見えます。

透明な中央面は CSS の `backdrop-filter` で実際のDOM背景を直接ぼかします。WebGLは中央面を塗らず、リム屈折・反射・厚みだけを透明レイヤーとして重ねます。これにより、背景の再描画位置がずれて不透明な板に見える経路を避けます。

## 共通パラメータ

初期値は `src/scripts/glass-config.ts` にあります。本番の Canvas とハーネスは同じ `data-*` パラメータと `src/scripts/glass-pbr.ts` を使うため、検証用だけ別の見た目になることを避けられます。

不透明度を調整するときは、シェーダー内の色ではなく最終マスクだけを変更します。背景色、すりガラス色、Canvas の CSS opacity を同時に変更しないでください。
