# 概要 (公開)

農業現場の熟練技を次世代に繋ぐ、スマート農業基盤の第一歩。同時に動く数十台の車両の軌跡を、リアルタイム・高精度に可視化するWebアプリ。

みちびきCLAS対応端末を独自開発し、誤差12cm測位を実現。「使ってみたい」が芽生える操作体験で、高齢者含む全員参加を達成。チーム連携強化・教育コスト減・作業効率18％向上を実現。

# デザインのポイント (公開)

1. 農業現場の車両の行動データから、親方の熟練技とチームの実践知を次世代に繋ぐスマート農業基盤
2. みちびきCLAS対応・通信一体型端末を開発し、理論値誤差12cmの高精度・高頻度データ取得を実現
3. ”使ってみたい”が芽生える操作体験で、「ITわからん」が口癖の人や高齢者含め関係者全員の参加を実現

# デザインが生まれた理由・背景 (公開)

北海道の広大な畑では、親方の指示で数十台の車両が同時に動く。

レポサクはその動きをリアルタイムに可視化することから始まり、位置確認の連絡回数を84％削減、作業効率を18％向上を達成。

さらに、データ解析とヒアリングを重ね、親方の“勘”という暗黙知を紐解いてきた。それは、刻々と変わる天候・土壌・資材・人…膨大な変数を掛け合わせ、作業を段取る熟練の技だ。

日本の農業は今、年齢中央値75歳、7割が後継者不在という危機にある。レポサクは、熟練技を次世代に繋ぎ、高齢化と人手不足を乗り越え、未来の完全自動農場へと繋ぐ。

そのためには、「全員」の「高精度な」データの継続的な取得が必須だ。

高齢者が多く、繁忙期は軍手を外す暇すらない農業現場に、高精度測位のテクノロジーを融かすデザイン。端末にUSBで給電さえすれば使える“負担のない体験”と、義務感ではなく好奇心から「使ってみたい」が芽生える体験を実装した。

# デザインを実現した経緯とその成果 (公開)

従来のGPSでは畝幅30cmの畑に対して精度が足りず、理論値誤差12cmを実現するため、みちびきCLAS対応端末を独自開発。SIMを内蔵することで「車両のUSBに挿すだけでデータは取れる」と案内。導入ハードルを下げた。

躓きがちなポイントは一つ一つ解消。インストールやサインアップの代わりに、紙の会員証をスマホのカメラにかざすだけで、Webブラウザでマップを閲覧可能にした。

全員参加型が実現し、「他の人の動きを見てサポートに行ける。指示待ちがなくなった」「新人がベテランの軌跡を重ねてうまく走れるようになった」といった声が寄せられている。

「使う自分が誇らしい」と感じられる体験も重視。マップ上で現実の車両とシンクロして動くハイテクな演出や、ゲームのようなUIが好評で、近隣農家さんへの“自慢”という形で自然に口コミが拡大。展示会でも注目を集め、全国181社に導入済、導入数は2年で3.3倍に増加。

# デザインの改良、競合・類似デザインとの差異 (非公開)

レポサクは【①作業の邪魔にならない②設定不要で使える③リアルタイム④データ精度】で差異化。
①繁忙期は手袋を外す暇もなく、作業をいちいち記録するのは現実的ではない (例:アグリノート)。 
レポサクは、端末にUSBで給電するだけでデータを取得、後からタグ付け成形でOKという”ゆるさ”から、農作業を邪魔しない。
②畑を事前登録しなければ利用開始できないシステムが多い中 (例: ザルビオ)、レポサクは設定ページを開かずとも基本機能を即日利用可能。必要に応じて段階的に設定機能を解放できる。
③他社システムのマップ更新は数分ごとで、その間に車両が数キロ移動することも (例: KSAS)。レポサクは1秒単位の更新で、リアルタイム性を実現。
④汎用フリート管理システムの誤差は数メートルだが、レポサクのCLAS対応GNSS受信機は誤差12cmで、1秒ごとに位置情報を取得。現実に近く、確証を持ってデータ分析が可能である。

# これまでの実績 (非公開)

2025 年時点で181 社に導入済、北海道TMRセンター(牛飼料の生産拠点)はシェア7割、農協24組合へも定着し、社数は2023年比3.3倍に伸長。九州など道外28社にも拡がる。

利用者からは「とにかく手間なく簡単」「感覚で捉えていた部分が数値化され、車両の稼働を最適化できた」と評価されている。

こうした成果が「誰一人取り残さない DX」として認められ、スマート農業成功事例としてデジタル田園都市国家構想に選定。さらに農林水産技術会議会長賞・イチBiz最優秀賞・CEATEC AWARD部門賞を受賞。

農業を超え、誤差12cmの高精度測位と高齢者も無理なく使える点が評価され、除雪・配送・クマ対策など19社と11自治体にも採用が進む。国内7500億円規模の位置情報プラットフォーム市場(*)へ横展開し、収益モデルを確立しながら自動農場実現の基盤を固めている。*デロイトトーマツミック経済研究所
